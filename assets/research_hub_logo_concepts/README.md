# GeoID: Research Hub Logo Concepts

This directory contains SVG logo concepts for the `GeoID: Research Hub` rebrand.

Files:
- `concept_01_orbital_hub.svg`: technical, networked, app-friendly wordmark lockup
- `concept_02_grid_beacon.svg`: geospatial/grid-oriented concept with a map-pin beacon feel
- `concept_03_ring_stack.svg`: cleaner enterprise-style hub emblem with stacked rings
- `concept_04_signal_arc.svg`: data-flow and sensing oriented mark with stronger motion
- `concept_05_orbital_hub_matrix.svg`: richer orbital-hub variant with layered rings, cross-links, and a sharper product tagline
- `concept_06_orbital_hub_constellation.svg`: more technical system-map evolution with constellation nodes and a hex core
- `concept_07_orbital_hub_command.svg`: densest orbital-hub direction with radial ticks and command-center energy

Notes:
- All concepts are pure SVG and easy to edit in Figma, Inkscape, or Illustrator.
- The current app palette was used so they fit the existing UI direction.
- These are concept-quality assets intended to help choose direction before making a final production logo.
