# Name Concept Logo Alternatives

Five SVG logo concepts for the app rebrand, one per name candidate.
All match the existing dark-navy palette: cyan `#16F4FF`, indigo `#1D35FF`, magenta `#FF1FB8`.
Format: 1400 × 420 px, pure SVG — open in Inkscape, Figma, or a browser to preview.

| File | Name | Mark concept | Feel |
|------|------|-------------|------|
| `concept_forge.svg` | **Forge** | Hexagon + apex spark + anvil dot | Action, craft, precision |
| `concept_flux.svg` | **Flux** | Three sinusoidal wave lines | Dynamic, data-flow, scientific |
| `concept_nexus.svg` | **Nexus** | Central hub node + 6 satellites | Platform, connected, ecosystem |
| `concept_meridian.svg` | **Meridian** | Globe arc with highlighted prime meridian | Reference standard, authority |
| `concept_vertex.svg` | **Vertex** | Triangle with apex glow + medians | Mathematical, precise, convergence |
