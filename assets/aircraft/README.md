# Earth Flight aircraft

`cessna_{hull,trim,glass,prop}.stl`: Earth Flight's default aircraft, one binary STL
per material, the way the flight sim's ships are stored (`assets/ships/`). The sim
loads them in `buildAircraft()` in `scripts/flightsim.js`.

| | |
|---|---|
| Model | Light aircraft, Cessna 172-class high-wing monoplane: 8.3 m long, 11.0 m span, fixed tricycle gear |
| Author | GeoID: generated by `scripts/make-aircraft-stl.py` (run it to rebuild) |
| Licence | This repository's licence (`LICENSE`); original geometry |
| Size | 1,104 triangles across the four files, about 55 KB |
| Frame | Metres; nose toward −Z, up +Y, right +X |

**Why it was generated, not sourced.** No downloadable aircraft model could be
confirmed from this machine with a licence that is clean for commercial use and a
named author. So the model is built from published Cessna 172 proportions as
original geometry: an approximation of the type, not a copy of any model. If a
CC0 or CC-BY model is adopted later, record its author, licence and link here and
in the Metadata tab entry (`GeoID_GIS/viewer/gis/osm-buildings.js`, "Earth Flight
aircraft").

## Helicopter

`heli_{hull,trim,glass,rotor,tailrotor}.stl`: the Helicopter in the same
picker, made by the same script.

| | |
|---|---|
| Model | Light turbine helicopter, Bell 206-class: 9.5 m fuselage, 10.2 m main rotor, 1.6 m tail rotor, skids |
| Author | GeoID: generated by `scripts/make-aircraft-stl.py` |
| Licence | This repository's licence (`LICENSE`); original geometry from published proportions, not a copy of any model |
| Size | 1,276 triangles across the five files, about 64 KB |
| Frame | Metres; nose toward −Z, up +Y. Each rotor is built about its own hub (main rotor axis +Y, tail rotor axis +X); `scripts/flightsim.js` places them at `HELI_MAIN_HUB` and `HELI_TAIL_HUB` and spins them |

It flies as a helicopter (`HELICOPTER FLIGHT` in `scripts/flightsim.js`): up/down
arrows are the collective (+20 / −25 m/s, doubled on boost), it is held level and yaws on the spot, hovers
at zero throttle, and tops out at 70 m/s (85 on the boost ramp) with no warp.
