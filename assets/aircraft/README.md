# Earth Flight aircraft

`cessna_{hull,trim,glass,prop,navred,navgreen,navwhite}.stl`: Earth Flight's default aircraft, one binary STL
per material, the way the flight sim's ships are stored (`assets/ships/`). The sim
loads them in `buildAircraft()` in `scripts/flightsim.js`.

| | |
|---|---|
| Model | Light aircraft, Cessna 172-class high-wing monoplane: 8.3 m long, 11.0 m span, fixed tricycle gear |
| Author | GeoID: generated by `scripts/make-aircraft-stl.py` (run it to rebuild) |
| Licence | Proprietary, all rights reserved (`LICENSE`); original geometry |
| Size | 22,196 triangles across the seven files, about 1.1 MB (second generation, 2026-10-25; the first was 1,104) |
| Frame | Metres; nose toward −Z, up +Y, right +X |

**Why it was generated, not sourced.** No downloadable aircraft model could be
confirmed from this machine with a licence that is clean for commercial use and a
named author. So the model is built from published Cessna 172 proportions as
original geometry: an approximation of the type, not a copy of any model. If a
CC0 or CC-BY model is adopted later, record its author, licence and link here and
in the Metadata tab entry (`GeoID_GIS/viewer/gis/osm-buildings.js`, "Earth Flight
aircraft").

## Second generation (2026-10-25)

Same frame, same principal dimensions, so the livery decals, the propeller
axis and the rotor hubs are where they were; built properly instead of
roughly:

- fuselages lofted through spline-resampled sections, 56 around;
- NACA 4-digit airfoils with cosine spacing: 2412 wings with 1.7° dihedral,
  outboard taper and washout, rounded tips; 0012 tails and rotor blades; a
  4412 propeller with 26° of twist;
- windows as glass lying on the hull (side, door, rear, windscreen; the
  helicopter's framed bubble and chin windows), door seams, a step;
- gear with tyres and spats (Cessna), upturned skids and arched cross tubes
  (helicopter), streamlined struts, antennas, a pitot, a landing light;
- navigation lights as their own files (`*_navred`, `*_navgreen`,
  `*_navwhite`), drawn emissive by the sim.

STL carries one flat normal per triangle; the loader (`creaseNormals` in
`scripts/flightsim.js`) rebuilds smooth normals with a 35° crease, so curves
shade smoothly and trailing edges stay sharp.

## Helicopter

`heli_{hull,trim,glass,rotor,tailrotor,navred,navgreen,navwhite}.stl`: the Helicopter in the same
picker, made by the same script.

| | |
|---|---|
| Model | Light turbine helicopter, Bell 206-class: 9.5 m fuselage, 10.2 m main rotor, 1.6 m tail rotor, skids |
| Author | GeoID: generated by `scripts/make-aircraft-stl.py` |
| Licence | This repository's licence (`LICENSE`); original geometry from published proportions, not a copy of any model |
| Size | 21,912 triangles across the eight files, about 1.1 MB (second generation; the first was 1,276) |
| Frame | Metres; nose toward −Z, up +Y. Each rotor is built about its own hub (main rotor axis +Y, tail rotor axis +X); `scripts/flightsim.js` places them at `HELI_MAIN_HUB` and `HELI_TAIL_HUB` and spins them |

It flies as a helicopter (`HELICOPTER FLIGHT` in `scripts/flightsim.js`): up/down
arrows are the collective (+20 / −25 m/s, doubled on boost), it is held level and yaws on the spot, hovers
at zero throttle, and tops out at 70 m/s (85 on the boost ramp) with no warp.

`livery-site-panel.png`, `livery-site.png`, `livery-site-mark.png`: the GeoID
livery decals (scripts/flightsim.js `addLivery`), cut from the website header's
logo `/assets/GeoID_logo_icon.png`: on a brand-navy panel for the white Cessna
(its "Geo" is white), bare for the navy helicopter, and its globe alone for
the fins.
