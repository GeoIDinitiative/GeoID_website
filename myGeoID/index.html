Demonstration only

myGeoID is a UI concept, not a live hazard tool

myGeoID is a visual prototype — not connected to any live weather data, hazard model, or geotechnical engine. Every value shown is synthetic, generated for interface design only.

  • Not a certified or operational hazard system.
  • No real precipitation, soil, slope-stability, or flood data is consumed.
  • Values must not be used for any safety, engineering, planning, or operational decision.
  • A design preview of future GeoID products.
