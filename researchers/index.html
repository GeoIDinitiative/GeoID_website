GeoID For Researchers

Your entry point to GeoID's research tools. The Research Hub and the shared data repository are both inside GeoHUB — a project is a real folder on disk, with ingest, analysis, figures and notes in the same layout our desktop application reads.

Open GeoHUB The architecture
Research Position

One Layered System

The Hazard App gives monitoring context, Resources provide materials and datasets, and the Research Hub is where project work happens.

Hazard App for context Monitored domains, terrain, and public-facing data.
Resources for inputs Crash courses, reference data, and shared repositories.
Research Hub for execution Project definition, preprocessing, solver setup, and outputs.
