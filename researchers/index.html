GeoID For Researchers

This page is the researcher-oriented entry point inside About. It separates the initiative-level story from the things a research user usually needs first: the Research Hub product, the shared data repository, hazard-facing context, and the project documentation that explains how the pieces fit together.

Research Position

The Research Hub Is A Product Inside The Initiative

Researchers should treat GeoID as a layered system. The initiative defines the mission. The Hazard App exposes monitoring context. Resources provide reusable materials and datasets. The Research Hub is where deeper project work happens.

Use the Hazard App for context Start with monitored domains, terrain context, and public-facing data organization.
Use Resources for inputs Pull crash courses, reference data, and shared repository paths when framing work.
Use Research Hub for execution Move into project definition, preprocessing, solver setup, and output generation.
